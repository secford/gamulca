# CodeGuess — онлайн-викторина для программистов

Угадывайте язык программирования, команды Linux, Git, SQL, Docker/Kubernetes, алгоритмы и веб-протоколы по небольшим фрагментам кода. Играйте с друзьями онлайн: создайте комнату, отправьте ссылку или код — и соревнуйтесь в реальном времени.

**Онлайн:** https://secford.github.io/gamulca/

## Как работает мультиплеер

GitHub Pages раздаёт только статические файлы, поэтому сервер игры не нужен. Комнаты работают через WebRTC (PeerJS):

- Хост создаёт комнату и становится авторитетным сервером игры в своей вкладке.
- Гости подключаются напрямую к хосту по P2P-каналу.
- Для установки соединения используется публичный signaling-сервер PeerJS (`0.peerjs.com`), сами вопросы и ответы идут напрямую между игроками.
- Хост должен держать вкладку открытой. Если хост закроет её, комната закроется.
- Игрок, подключившийся во время игры, попадает в режим наблюдателя.

## Как играть

1. Введите имя.
2. Нажмите **«Создать комнату»** — вы станете хостом.
3. Отправьте друзьям ссылку (**«Ссылка»**) или код комнаты из 6 символов.
4. Друзья вводят имя и код, затем нажимают **«Войти»**. Ссылка с `?room=КОД` подключает автоматически, если имя уже сохранено.
5. Когда в комнате минимум 2 игрока, хост нажимает **«Начать игру»**.
6. Отвечайте кнопками или клавишами `1–4` / `A–D`.
7. После раунда показывается правильный ответ, очки и объяснение.

Настройки (режим, сложность, время, категории, тема) меняет только хост. Гости видят их синхронно.

## Режимы

| Режим | Вопросов | Время | Особенности |
|-------|----------|-------|-------------|
| Классика | 15 | 10–30 с | Очки за правильный ответ |
| Блиц | 10 | до 10 с | Множитель очков ×1.5 |
| Выживание | до 30 | 10–30 с | Ошибка или таймаут — выбывание; побеждает последний выживший |

## Очки

- База: 7 (лёгкий), 10 (средний), 15 (сложный).
- Бонус за скорость: до +5 за быстрый ответ.
- Серия: +2 за каждый правильный ответ подряд (максимум +6).
- Блиц умножает итог на 1.5.
- Правильный ответ всегда перемешивается по позициям A–D.

## Категории

- Языки программирования — 60 вопросов
- Linux / CLI — 30
- Git — 30
- SQL / Базы данных — 30
- Docker / Kubernetes — 30
- Алгоритмы — 35
- Web / HTTP — 35

Всего 250 вопросов: `data/questions.json`. После каждого раунда показывается объяснение правильного ответа. Чтобы добавить свой вопрос, используйте формат:

```json
{
  "cat": "langs",
  "diff": "medium",
  "code": "console.log('hi')",
  "options": ["JavaScript", "Java", "Python", "Ruby"],
  "answer": "JavaScript",
  "explain": "console.log — встроенный вывод JavaScript."
}
```

Поле `explain` обязательно. Вопросы с 5+ вариантами или повторяющимися вариантами игра отклонит при загрузке.

## Запуск локально

Вопросы загружаются через `fetch`, поэтому открывать `index.html` двойным щелчком нельзя — нужен HTTP-сервер.

```bash
npm start
```

Откройте `http://localhost:8080`. На Windows также можно запустить `start.bat`.

Без Node.js подойдёт любой статический сервер:

```bash
python -m http.server 8080
```

## Публикация на GitHub Pages

1. Запушьте изменения в ветку `main`.
2. Откройте репозиторий на GitHub → **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через минуту сайт обновится по адресу `https://<логин>.github.io/<репозиторий>/`.

Файл `.nojekyll` уже добавлен, чтобы GitHub Pages не обрабатывал проект через Jekyll. Все пути относительные, поэтому сайт работает и в подпапке репозитория.

## Ограничения

- Нужен современный браузер с поддержкой WebRTC.
- Публичный PeerJS signaling-сервер может быть недоступен в некоторых сетях; тогда соединение не установится.
- Нет аккаунтов, истории игр и серверной модерации — игра рассчитана на друзей.
- Хост закрыл вкладку — комната завершилась.

## Структура

```
index.html              — разметка
static/style.css        — стили и темы
static/peerjs.min.js    — PeerJS 1.5.5 для P2P-комнат
client/app.js           — игровой движок и сетевой слой
data/questions.json     — база вопросов
server.js               — локальный статический сервер (не нужен на GitHub Pages)
start.bat               — запуск локального сервера на Windows
```
