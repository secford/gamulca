# CodeGuess — угадай язык программирования

Сетевая многопользовательская викторина: определяйте язык программирования, команды Linux, Git, SQL, Docker/Kubernetes, алгоритмы и веб-протоколы по небольшим фрагментам кода.

## Запуск

```bash
npm install
npm start
```

Или запустите `start.bat` на Windows.

Сервер слушает `0.0.0.0:8080`. Порт можно изменить переменной окружения:

```bash
set PORT=3000
npm start
```

Откройте в браузере `http://localhost:8080` (или `http://<IP-сервера>:8080` с другого устройства).

## Деплой на GitHub и Render

GitHub Pages не подойдёт: игре нужен Node.js-сервер и WebSocket. Код можно хранить на GitHub, а саму игру запустить на Render — это бесплатно.

1. Создайте пустой репозиторий на GitHub.
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "CodeGuess: 250 questions and explanations"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

3. Зайдите на [render.com](https://render.com) и войдите через GitHub.
4. Нажмите **New → Blueprint**, выберите репозиторий. Render прочитает `render.yaml`.
5. Нажмите **Apply / Deploy** и дождитесь сборки.
6. Откройте выданный Render URL и отправьте его друзьям.

На бесплатном тарифе Render сервер засыпает после 15 минут без запросов; первый заход после сна занимает около минуты. Если нужен сервер 24/7, используйте платный план, Railway, Fly.io или VPS.

Альтернатива без облака — запустить игру на своём ПК и открыть доступ через туннель:

```bash
cloudflared tunnel --url http://localhost:8080
```

Или `ngrok http 8080`. Друзьям нужно отправлять публичный URL из туннеля, пока ваш ПК включён.

## Как играть

1. Введите имя и нажмите «Войти».
2. Первый вошедший становится хостом: он выбирает режим, сложность, время, категории и тему, а затем запускает игру.
3. Нужно минимум 2 игрока. Присоединившиеся во время партии становятся наблюдателями до следующей игры.
4. Отвечайте кнопками или клавишами `1–4` / `A–D`.
5. После раунда показывается правильный ответ, начисленные очки и таблица результатов.

## Режимы

| Режим | Вопросов | Время | Особенности |
|-------|----------|-------|-------------|
| Классика | 15 | 10–30 с | Очки за правильный ответ |
| Блиц | 10 | до 10 с | Множитель очков ×1.5 |
| Выживание | до 30 | 10–30 с | Ошибка или таймаут — выбывание; побеждает последний выживший |

## Очки

- База: 7 (лёгкий), 10 (средний), 15 (сложный).
- Бонус за скорость: до +5 за быстрый ответ.
- Серия: +2 за каждый правильный ответ подряд (максимум +6).
- Блиц умножает итог на 1.5.
- Правильный ответ всегда перемешивается по позициям A–D.

## Категории

- Языки программирования — 60 вопросов
- Linux / CLI — 30
- Git — 30
- SQL / Базы данных — 30
- Docker / Kubernetes — 30
- Алгоритмы — 35
- Web / HTTP — 35

Всего 250 вопросов: `server/questions.json`. После каждого раунда показывается объяснение правильного ответа. Чтобы добавить свой вопрос, используйте формат:

```json
{
  "cat": "langs",
  "diff": "medium",
  "code": "console.log('hi')",
  "options": ["JavaScript", "Java", "Python", "Ruby"],
  "answer": "JavaScript",
  "explain": "console.log — встроенный вывод JavaScript."
}
```

Поле `explain` обязательно. Вопросы с 5+ вариантами или повторяющимися вариантами сервер отклонит при запуске.

## Возможности

- Комнаты на 2–12 игроков, роль хоста и наблюдатели
- Три режима, четыре темы оформления (Неон, Кибер, Матрица, Vaporwave)
- Очки за скорость и серии, расшифровка раунда и объяснение ответа
- Синхронизация таймера с сервером
- Таблица лидеров и подиум, повторная игра без перезагрузки
- Адаптивная вёрстка и управление с клавиатуры

## Структура

```
server/index.js       — логика комнаты, раундов, очков и режимов
server/questions.json — база вопросов
client/app.js         — клиентская логика и интерфейс
templates/index.html  — разметка
static/style.css      — стили и темы
```
