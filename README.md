# CodeGuess — угадай язык программирования

Статическая викторина для GitHub Pages: определяйте язык программирования, команды Linux, Git, SQL, Docker/Kubernetes, алгоритмы и веб-протоколы по небольшим фрагментам кода. Играйте против ботов — сервер и WebSocket не нужны.

**Онлайн:** https://secford.github.io/gamulca/

## Почему без сервера

GitHub Pages раздаёт только статические файлы, поэтому Node.js-сервер и Socket.IO там работать не могут. Вся игровая логика перенесена в браузер: настройки, очередь вопросов, таймеры, очки, режим выживания и боты. Настоящий сетевой мультиплеер возможен только с отдельным сервером (Render, Railway, VPS и т.п.).

## Запуск локально

Так как вопросы загружаются через `fetch`, открывать `index.html` двойным щелчком нельзя — нужен HTTP-сервер.

```bash
npm start
```

Откройте `http://localhost:8080`. На Windows также можно запустить `start.bat`.

Без Node.js подойдёт любой статический сервер:

```bash
python -m http.server 8080
```

## Публикация на GitHub Pages

1. Запушьте изменения в ветку `main`.
2. Откройте репозиторий на GitHub → **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через минуту сайт обновится по адресу `https://<логин>.github.io/<репозиторий>/`.

Файл `.nojekyll` уже добавлен, чтобы GitHub Pages не обрабатывал проект через Jekyll. Все пути относительные, поэтому сайт работает и в подпапке репозитория.

## Как играть

1. Введите имя и нажмите «Войти».
2. Настройте режим, сложность, время, количество ботов, категории и тему.
3. Нажмите «Начать игру» — вы играете против ботов (от 1 до 11).
4. Отвечайте кнопками или клавишами `1–4` / `A–D`.
5. После раунда показывается правильный ответ, начисленные очки и таблица результатов.

## Режимы

| Режим | Вопросов | Время | Особенности |
|-------|----------|-------|-------------|
| Классика | 15 | 10–30 с | Очки за правильный ответ |
| Блиц | 10 | до 10 с | Множитель очков ×1.5 |
| Выживание | до 30 | 10–30 с | Ошибка или таймаут — выбывание; побеждает последний выживший |

## Очки

- База: 7 (лёгкий), 10 (средний), 15 (сложный).
- Бонус за скорость: до +5 за быстрый ответ.
- Серия: +2 за каждый правильный ответ подряд (максимум +6).
- Блиц умножает итог на 1.5.
- Правильный ответ всегда перемешивается по позициям A–D.

## Категории

- Языки программирования — 60 вопросов
- Linux / CLI — 30
- Git — 30
- SQL / Базы данных — 30
- Docker / Kubernetes — 30
- Алгоритмы — 35
- Web / HTTP — 35

Всего 250 вопросов: `data/questions.json`. После каждого раунда показывается объяснение правильного ответа. Чтобы добавить свой вопрос, используйте формат:

```json
{
  "cat": "langs",
  "diff": "medium",
  "code": "console.log('hi')",
  "options": ["JavaScript", "Java", "Python", "Ruby"],
  "answer": "JavaScript",
  "explain": "console.log — встроенный вывод JavaScript."
}
```

Поле `explain` обязательно. Вопросы с 5+ вариантами или повторяющимися вариантами игра отклонит при загрузке.

## Возможности

- Игра против 1–11 ботов с разным уровнем навыка
- Три режима, четыре темы оформления (Неон, Кибер, Матрица, Vaporwave)
- Очки за скорость и серии, расшифровка раунда и объяснение ответа
- Таблица лидеров и подиум, повторная игра без перезагрузки
- Адаптивная вёрстка и управление с клавиатуры
- Полностью статическая сборка для GitHub Pages

## Структура

```
index.html            — разметка
static/style.css      — стили и темы
client/app.js         — клиентская логика, боты и игровой движок
data/questions.json   — база вопросов
server.js             — локальный статический сервер (не нужен на GitHub Pages)
start.bat             — запуск локального сервера на Windows
```
